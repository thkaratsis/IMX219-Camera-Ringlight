Suggested topics: `pcb`, `electronics`, `imx219`, `camera`, `led`, `ring-light`, `hardware`

The designer has confirmed testing at 5 V. Outstanding component details remain documented in the hardware notes. Create a public GitHub repository without an automatic license or README, then upload the contents of this folder with README.md at the root. Retain LICENSE.md; do not replace it with MIT or another open-source license.

Keep original detailed schematic, PCB PDF, OBJ and editable CAD outside the public repository. Git ignore rules do not protect previously committed files or prevent forced uploads. The included photographs and Gerbers necessarily expose aspects of the design. Never commit private originals even temporarily: deletion does not remove them from Git history.
